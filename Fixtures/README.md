# Scanner fixtures

Fixtures are generated in uniquely named temporary directories by the test suite rather than storing copies of installed applications or personal inventory data in the repository.

Tests include native Info.plist bundles, local store receipt presence, Homebrew receipts/configuration and multiple kegs, PKG query output, MacPorts installed output, modern/legacy Nix JSON, Setapp framework markers, Steam KeyValues manifests and the JetBrains-documented legacy Toolbox layout.

These are representative adapter fixtures, not proof of current live-provider compatibility. See Docs/SOURCE_SUPPORT.md for verification boundaries.

# Technical corrections and declared limitations

Current interpretations for **v1.1.0 / build 108** complement section 29 of [SPEC](../SPEC.md). Build-specific reports retain historical evidence; this summary does not turn those checks into final-release validation.

1. **Toolchain:** SwiftPM plus the installed macOS 26.5 SDK builds the native app locally without full Xcode. The CLT native-build-system fallback is deprecated upstream. Hosted Xcode app/test compilation and unit/package validation have run successfully on the starting main commit; full CI on the final documentation commit remains required. See [CI](CI.md) rather than treating old local-Xcode limitations as absence of hosted execution.
2. **Homebrew discovery and effects:** discovery reads local receipts/configuration and uses bounded typed installed-state queries to distinguish current registration from retained metadata. It does not evaluate recipes or fetch package metadata through `brew info`. Separately confirmed removal invokes normal official Homebrew operations after fresh trust/state/effect review. Unsupported receipt formats/hooks and uncertain custom executables remain guided; keg-only metadata stays Unknown without evidence.
3. **Store evidence:** receipt presence is inferred origin, not authenticated ownership/purchase. Offline validation of arbitrary third-party receipts is not implemented. No account access, receipt refresh or server request is attempted.
4. **Dates:** receipt/manager time describes that recorded installation event or version. It may follow an earlier install, and app self-updates can make the manager version older than the bundle. File Created/Modified stay separate. No creation-date fallback is used for Installed.
5. **Usage:** the restricted CLI originally returned no Spotlight dates. The actual GUI and an unrestricted read-only scan provided 25 observations. Availability depends on indexing/permissions; missing does not mean unused.
6. **Provider coverage:** MacPorts, Nix, Setapp, Steam and Toolbox are absent here. Fixtures cover recognized formats only. Modern Toolbox generated-launcher association is inferred; missing/unknown/dynamic launchers remain unsupported.
7. **Size:** use logical bytes; directory traversal does not follow symlinks, hard links are counted once within a footprint, and incomplete traversal remains unknown/partial. No global storage sum or recoverable-space promise is shown. APFS clone/compression/shared-dependency accounting is not implemented.
8. **Persistence:** versioned Codable inventory snapshot (schema 1, optional health fields, 32 MiB) replaces the original SQLite proposal. Older snapshots without health remain decodable/stale; future unsupported schemas require refresh. Separate bounded identity-name history migrates prior snapshot name evidence; confirmed-removal records remain distinct. None of these records grants cleanup authority.
9. **Distribution:** outside App Sandbox, ordinary user permissions, no entitlement or privacy bypass. Local ad-hoc signing does not provide Developer ID trust or notarization. No paid-account distribution capability is claimed.
10. **UI extras:** optional native column visibility and ordering are implemented on macOS 14+, with fixed columns on macOS 13. Actual checkbox hiding/reset passed after a macOS 27 table-refresh workaround. Drag reordering is exposed by the native API but was not confirmed by automation. GUI interactions now have actual inspection evidence; full VoiceOver and keyboard audits remain pending.
11. **Uninstall:** implemented per-installation Direct/Interactive/Guided levels and independent protection override, source-specific production adapters, immutable preview, single-use confirmation and fresh checks. Homebrew, exact MacPorts and supported mutable Nix profiles can be direct; eligible native/Store/limited PKG removal is bundle-only; vendor/Steam handoffs are interactive; Setapp/Toolbox use guidance. Privileged MacPorts needs trusted matching signing and OS authority, unavailable in ad-hoc builds. Actual destructive effects and signed deployment remain unverified; see [current matrix](UNINSTALL.md).

[Verification](VERIFICATION.md) distinguishes compilation, synthetic/fixture coverage, read-only live observations, hosted CI and unverified effects. Default inventory requires no network; explicit official-guidance opening performs an ephemeral HTTPS HEAD/redirect check. A failed strategy never falls back to deletion. No release readiness is claimed before full final-commit CI and applicable gate review.

Current product refinements: settings use explicit Done/Cancel drafts; Advanced is now Information; About points to the verified official repository. Public screenshots use isolated fictional demo data exclusively. Apple Silicon is primary; Intel is optional rather than a release gate.

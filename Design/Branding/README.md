# Official Macventory branding

Original artwork supplied by the project owner for Macventory. The original PNGs remain unchanged:

- app-icon-source.png — icon artwork, 1254×1254. Used for Finder/Dock/application icon and the compact native app header/About icon.
- brand-lockup-reference.png — logo and wordmark reference, 1254×1254. Used in the README; never substituted for the small app icon.

SHA-256:

```
d789c1e951353b4e07a908fbaf682eaebc9e76678db5f64295b23405cd991f17  app-icon-source.png
958075d45bd12069443702117ed126f2b5aeac4cbf2588aad10b91ac1bdbe033  brand-lockup-reference.png
```

The regenerable intermediate Resources/Macventory.iconset contains 16, 32, 128, 256 and 512-point images at 1×/2× and is intentionally ignored, not a required checkout input; Resources/Macventory.icns is compiled with Apple's iconutil. No cropping, recoloring, replacement artwork or proportion changes. Downsampling uses high-quality native AppKit interpolation. The supplied opaque background is preserved. The header uses the icon plus native text to remain legible, and About uses the actual bundled icon.

Regenerate from the repository root:

```sh
swift -module-cache-path .build/module-cache scripts/make-icon.swift Resources/Macventory.iconset
iconutil -c icns Resources/Macventory.iconset -o Resources/Macventory.icns
```

## In-app header derivative

Resources/ToolbarMark.png now provides the compact alpha-aware toolbar artwork instead of drawing the opaque app ICNS there. It is generated by scripts/make-toolbar-mark.swift using an explicit foreground crop and near-white alpha mask. The original source PNGs and the Finder/Dock ICNS are unchanged. About retains the official application icon with native rounded clipping. See Docs/SETTINGS.md.

The toolbar item disables the macOS 26 shared toolbar background so the alpha-aware mark and native text are unframed. Native SF Symbols are used for About link affordances; no GitHub/LinkedIn brand-icon assets or fonts are bundled. Original PNGs retain their documented hashes.

## Repository inputs

Keep both original PNGs and this provenance document. The icon source feeds the native icon/toolbar generators; the lockup is the README hero. Keep the compiled ICNS and toolbar PNG under Resources because app bundling and the Xcode resource phase copy them directly. The ten intermediate iconset PNGs can be recreated with the commands above and are excluded from Git/source packages. Ordinary builds use the existing approved derivatives and do not regenerate or redesign them.
